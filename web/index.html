    I want to dedicate this section here to explain a bit of the project, the main idea was to explore computer vision while implementing every important algorithm by hand, so no opencv and libraries like that, I used C++, and looking at my resume, you may be thinking, why not just use C? there are two main reasons:

    1) I actually really like C++, and just wanted to use it again in a project that I'm proud

    2) since the idea for the project was to allow me to write all the cool algorithms, C++ was better then C here, just because of the extreme amount of features already implemented on the language, like VECTORS, contexpr(this one came in C23 but weaker), and a lot more really, so I wouldn't "waste" time writing stuff that I already know, I just wanted to focus on plain CV this time.

    I know that this project is extremely complicated, with loads of different algorithms, so I wanted to make it easy to show to anyone it, so I decided to use webassembly and create this very basic UI you are seeing right now, but there is a problem, I'm not gonna go in detail, you can read the README for the reasons, but the algorithms used here themselfs are very expensive and slow, there is no escaping that, I'm doing grayscale, gaussian blur, harris, SIFT like algo, RANSAC and other algos, so there are limitations, with larger multiple images, the C++ will do the conversion, but any sort of update and change on the browser side will not diplay it, and the browser also may crash, so if you wanna do a hard test, I invite you to clone the repo and test it on your machine

    Just to end then, I had a lot of fun writing this, people think that with ML's the field of CV is already solved, but using and writing these algorithms in this block by block way has lead me to some other type of thinking, maybe mathmatics and the realm of CS is really just starting, there is a batter way of doing computation faster and with less memory consuption then just leaving the work to probabilistic models, we just need to find these ways
